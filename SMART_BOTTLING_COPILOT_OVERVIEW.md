# Smart Bottling Line Copilot: System Overview

A “Smart Bottling Line Copilot” is a plug-and-play AI + sensor system designed to optimize factory operations and empower non-technical users with actionable insights. Key features include:

## Features

- **Tracks Machine Health**
  - Predictive maintenance to prevent downtime and reduce unplanned outages.

- **Flags Bottlenecks**
  - Identifies process slowdowns and helps reduce Mean Time To Repair (MTTR).

- **Detects Product Defects**
  - Monitors quality to improve output, increase customer confidence, and reduce returns.

- **Provides Actionable Insights to Non-Technical Factory Owners**
  - Delivers leadership visibility of the factory floor and supports quality decision making.

- **Copilot Chat Interface**
  - Enables users to ask questions such as: "What is the last time a machine went down and why?"

- **Event Logging & Categorization**
  - Logs events with severity levels and categorizes them for easy review.

- **Notifications for Events**
  - Sends alerts for critical events to ensure timely response.

---

This system is designed to be intuitive, insightful, and accessible for all factory stakeholders.
